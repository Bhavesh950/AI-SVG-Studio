# 🎨 AI SVG Studio

AI-powered SVG Banner & Infographic Generation Engine built using Python, Streamlit, Gemini, and reusable SVG templates.

## 🚀 Features

- AI-powered content and design specification generation
- Gemini integration
- Multiple SVG design templates
- Feature highlights
- Step-by-step layouts
- Statistics layouts
- Comparison layouts
- Quote / highlight layouts
- Multiple color themes
- Live SVG preview
- SVG source code viewer
- Download generated SVG
- Download generated SVG as ZIP
- Responsive and scalable SVG format

## 🧠 How It Works

The application follows this workflow:

User Input
↓
Gemini AI
↓
Structured Design Specification
↓
Python Template Selection
↓
SVG Rendering
↓
Live Preview
↓
SVG / ZIP Download

Gemini is responsible for generating the content and design specification.

Python is responsible for rendering the final SVG using reusable templates.
